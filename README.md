# SuperNatural - projeto front-end

Este projeto vem a entender o bom uso de html e css
sobre as paginas web e bom uso de programação

## Oque foi feito

- Criação de estrutura de HTML e Pagina
- Organização de conteúdo em seções
- uso de elementos de HTML `herdar`,`nav`,`main`,`section`,`article` e `table`
- colocamos banner
- fizemos estilização de css
- definomos cores, fortes, espaçamentos e layout visual

## Estrutura do projeto

- `index.html` - estrutura da pagina
- `style.css` - estilo de layout do site
- `imagem/` - imagens usadas do projeto

## Tecnologias utilizadas

- HTML
